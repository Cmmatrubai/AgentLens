# AgentLens desktop prototype 04 — Quiet Lab

A disposable prototype authorized by the user's September 6 request. Iterations 01–02 use sample data; iteration 03 adds one real read-only recording. No production or protected prototype changes.

## Experience

A quiet desktop workspace that moves from saved tasks to a two-attempt comparison, then to exact illustrative evidence. Strong hierarchy, subdued navigation, one main next action, and meaningful motion. No opaque model score or population-level ranking. Each result is scoped to the shown attempts.

## Preserved foundation

- Desktop window chrome, collapsible workspace sidebar, task search, status filters, and repository filters.
- Three distinct saved task examples and comparison detail, including passing, failing and incomplete evidence.
- Comparison summary, acceptance-check matrix, important differences, and expandable execution context.
- Evidence drawer with check output, illustrative patch and source context.
- Save-as-case form, persisted local evaluation cases, replay simulation with cancellation, and command palette.
- Motion shared-layout navigation and tabs, staggered entry, drawer and dialog transitions, progress feedback, and reduced-motion support.
- Iterations 01–02 operate on demonstration data. Iteration 03 has a clearly labeled real-recording route with read-only local access. No API keys, model execution, telemetry upload, provider performance claims or publishing.

## Iteration 02

The user approved the direction and the recommended next workflow. Extend the original visual system in its existing isolated worktree; preserve the original source archive. Lead the user through choosing a case, selecting model roles, reviewing a frozen setup, watching meaningful progress, and inspecting the result.

The live view gives each attempt one current action, restrained stage motion and a compact progress path. Technical context sits behind an explicit expansion. Cancellation and interruption are first-class views; a reload never silently reports success. Real provider settings and credentials are intentionally absent because this is a sample playback.

Configuration affects the final projection: selected conditions control denominators and headlines; model identity stays attached to its output even when baseline/candidate roles are swapped. Full sample-attempt timings are labeled as such. The sidebar keeps the current run reachable while exploring other pages.

The real evaluation contract and AI's optional role are recorded in `docs/comparison-data-contract.md`. Homepage aggregation, provider execution and production persistence remain future integration work.

## Iteration 03

The user approved connecting an existing recording before the controlled comparison, and selected Sol/high versus Terra/high for that later comparison. The connected T01-A1 view leads with process completion and observed command failures. It keeps the historical human assessment separate and reveals commands, final Git evidence, all original events and source metadata on demand.

The new route suppresses fictional repository/current-run navigation and labels the local connection as real evidence. Sample task workflows keep their demo labels. Progress messages are generic agent messages, while the final message remains independently inspectable. Compound test-command outcomes remain unknown when the recording cannot attribute individual results.

Use the same restrained motion, mint accent, compact typography and accessible dialogs as the approved prototype. Preserve keyboard focus on close and prevent the global command palette from stacking over an evidence dialog. Keep output and diffs within bounded scroll areas at desktop and narrower widths. Local private configuration and actual evidence screenshots are excluded from Vite development file serving.

## Iteration 04

One real controlled pair now occupies a dedicated comparison route. Keep the same quiet hierarchy: task, bounded outcome, two model cards, seven aligned conditions. Each condition opens independently produced evidence; each attempt opens its observed commands, agent messages and final Git state. Technical identities and experiment limits stay in the details dialog.

Unknown checks are neutral. Evaluation completion is separate from certainty, so an inconclusive completed evaluator does not appear perpetually running. Refreshed drawers reconcile their selected evidence by stable identity. Both actual runs passed, but no winner badge or model-wide conclusion is shown. The native and browser views read preserved private evidence; they do not execute models on load. Setup and illustrative home analytics remain demo workflows.
