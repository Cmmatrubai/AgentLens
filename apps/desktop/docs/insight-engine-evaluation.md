# Evaluating AgentLens insights

This rubric evaluates generated interpretations, separately from the correctness of the coding attempts. Automated structural checks are necessary but insufficient for meaningful analysis.

For each run, retain the comparison input hash, selected evidence and omissions, prompt/analyzer versions, configured analysis model, output, latency and provider-reported usage. Reviewers score the analysis against the actual evidence, without seeing the comparison model brands when practical.

| Question                                                             | Review label                                        |
| -------------------------------------------------------------------- | --------------------------------------------------- |
| Does every citation resolve to the claimed attempt and exact source? | Valid / Invalid (automatic)                         |
| Does the cited evidence support every material observation?          | Supported / Partly supported / Unsupported          |
| Is the interpretation useful for this task's requirements?           | Useful / Incidental / Misleading                    |
| Does it preserve contradictions, missing checks and capture limits?  | Preserved / Omitted / Misrepresented                |
| Does it avoid treating an agent report as independent proof?         | Yes / No                                            |
| Do summaries and interpretations stay within visible excerpt scope? | Yes / No                                            |
| Is abstention appropriate when no material difference is supported?  | Appropriate / Forced difference / Missed difference |

Release gate: evaluate C01 without putting its authored notes into the prompt, then a real held-out task that was not used to develop the rubric. Include both attempt orders and repeat analysis to check material contradictions. Report the number of cases, findings and reviewers alongside results. One case is not a model leaderboard or proof that the insight engine generalizes.

Offline contract tests include synthetic comparisons with different tasks/model identifiers, absent checks, incomplete recordings, source changes and malicious-looking instructions inside recorded text. These verify application behavior; they do not establish the real model's semantic quality or resistance to injected instructions.

Initial completed live evaluation: one TokenRouter GLM-5.3 C01 request completed after response-limit tuning, producing three findings in 206.406 seconds. One agent reviewer checked the original output against the selected excerpts: 15/15 citation references resolved; one finding was supported and two were partly supported, with useful core differences in all three. The incomplete earlier requests remain in history. See [the live report](../qa/insight-engine/TOKENROUTER-LIVE.md) and [review qualifications](../qa/insight-engine/COMPLETION-CONTROLS.md). Repeated analysis, reversed attempt order and a second real comparison are still required before the quality release gate passes. No general success rate, cost or speed is claimed.

Concise-generation iteration: `comparison-rubric-v3` enforces concise generation separately from legacy saved output. A second completed C01 request produced three findings in 182.061 seconds, with card summaries 56% shorter than the prior output. All 12 citation references resolved, but one agent reviewer found scope/provenance overstatements in all three findings under the explicit claim-level criterion. The semantic release gate remains unmet; prompt instructions alone did not resolve it. See [the concise-findings evaluation](../qa/insight-engine/CONCISE-FINDINGS.md).

Support-review iteration: a separate, consented reviewer now assesses every text section and stores its result without editing the draft. The first live protocol incorrectly marked all three known problematic C01 findings supported. The revised `support-v2` / `evidence-support-v2` protocol requires all seven sections of each finding to pass; its one live request exhausted 24,000 output tokens with no answer text. No findings were promoted from that request. Offline tests verify complete section coverage, citations, conservative aggregation, consent, persistence and failure handling; they do not establish reviewer quality. Both live outcomes and the original drafts are preserved in [the support-review report](../qa/insight-engine/SUPPORT-REVIEW.md). The quality release gate remains unmet, including a completed accurate section review, held-out evidence, repetitions and reversed attempt order.

Model-selection iteration: seven models/configurations were screened against the unchanged C01 draft, with an agent-authored three-problem rubric and six supported controls written before outputs arrived. Three configurations produced structurally valid review results. Terra/medium and Sol/medium detected only one of the three primary problems; DeepSeek Flash detected none. Terra retained all six control labels and had a lower observed time/list-price estimate than Sol, making it the next development candidate rather than an approved reviewer. No model passed the predeclared gate. See the [complete timings, cost assumptions, failures, scoring caveats and plans](../qa/insight-engine/MODEL-SELECTION.md). The existing draft and application settings were preserved.

Claim-and-passage iteration: `support-v4` / `evidence-support-v4` validates complete ordered claim coverage and resolves selected line ranges into exact passages. Source metadata and saved attempt facts remain separately labeled and reviewable before consent. Two earlier v3 trials failed through output exhaustion or altered quotations; v4 shortened one completed response but rejected invalid ranges. No live result from this iteration was promoted, and known semantic problems remain. See the [three preserved trials and independent agent audit](../qa/insight-engine/PASSAGE-REVIEW-EVALUATION.md). Exact passage provenance does not establish atomicity, relevance, entailment or a trustworthy verdict.


Catalog iteration (2026-09-14): `support-v5` / `evidence-support-v5` replaces generated coordinates with fixed passage IDs and adds exact task requirements as distinct evidence. One Terra/medium request passed local validation (21 units, 52 claims, 100 valid passage selections) in 38.249 seconds. Semantic detection remains 1/3 frozen gates; six controls were retained, and task requirements were correctly attributed. The benchmark result was not promoted into the saved comparison. See the [catalog review evaluation](../qa/insight-engine/CATALOG-REVIEW-EVALUATION.md). Earlier v3/v4 failures remain historical records.


Semantic regression baseline (2026-09-14): a new [six-case relation suite](../qa/insight-engine/SEMANTIC-EVALUATION.md) tests supported/overclaim contrasts for imports, type guards and causal attribution. The unchanged v5 reviewer detected 3/3 overclaims and retained 3/3 controls; exact verdict agreement was 5/6. This establishes narrow synthetic coverage, not held-out accuracy, and does not erase the C01 misses. The suite preserves labels outside provider inputs, validates every output and keeps unusable cases in its result set.


A [controlled evidence-volume extension](../qa/insight-engine/SEMANTIC-CONTEXT-EVALUATION.md) raised selected excerpt size to about 46,600 characters while preserving the six original claims and relevant passages. It again detected 3/3 overclaims and retained 3/3 controls (6/6 exact labels in this single run). It increased input usage about 10.6-fold and did not reproduce the C01 failure. This does not establish robustness to similar distractors, evidence position, compound claims or wrong-attempt attribution.


[Compound claims and attempt attribution](../qa/insight-engine/SEMANTIC-CHALLENGE-EVALUATION.md) were checked in two further six-case suites. All six overclaims were detected and six controls retained; exact labels were 5/6 and 6/6. Target-span scoring does not count unrelated paragraph concerns as detection. These synthetic passes do not establish the cause of the real C01 failure; the next investigation returns to its exact wording and evidence.

Exact C01 granularity trial: three requests each reviewed one unchanged original unit against all original selected evidence. It still detected only the causal concern; the false two-symbol import was accepted and the unconditional title retained its ambiguity. Narrowing the requested review did not fix the misses. The original draft stays unchanged. See [the granularity report](../qa/insight-engine/C01-GRANULARITY-EVALUATION.md).
